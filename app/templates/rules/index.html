Comment modifier les règles

Éditez directement le fichier {{ rules_path }}. Rechargez cette page pour voir les règles mises à jour. Cliquez sur « Appliquer les règles » pour catégoriser les transactions importées. 

rules:
  - name: "Exemple"
    label_contains: "MOT_CLE"   # ou label_regex: "(?i)pattern"
    entity: "Nom de l'entité"   # facultatif — crée l'entité si inexistante
    entity_type: FOURNISSEUR    # CLIENT | FOURNISSEUR | SALARIE | ORGANISME | AUTRE
    category: "Libellé catégorie"
    account: "707"              # facultatif — crée une écriture comptable
                                #   compte 6xx → débit charge / crédit banque
                                #   compte 7xx → débit banque / crédit produit
Génération automatique d'écritures

Lorsqu'une règle définit le champ account, l'application des règles crée automatiquement une écriture comptable équilibrée dans le journal BQ, dans l'exercice qui couvre la date de la transaction. La transaction bancaire est alors automatiquement rapprochée à la ligne d'écriture côté banque. Le compte indiqué doit être un compte du plan comptable (non en-tête) commençant par 6 (charge) ou 7 (produit).
